# NPS Water Supply Vulnerability Assessment App

Shiny app for exploring vulnerability scores and rankings for National Park Service water supplies under changing weather and hydrologic conditions.

Part of [Water Vulnerability Analytics (WaVA)](https://github.com/Water-Vulnerability-Analytics). The indicators and input data are produced by [`nps_water_vulnerability`](https://github.com/Water-Vulnerability-Analytics/nps_water_vulnerability). This app was split out of that repo's `rapid_app/` folder with its full commit history.

## Contents

- `app.R`: the Shiny app
- `calc_vulnerability_index.R`: combines indicators into the vulnerability index (sourced by `app.R`)
- `app_data/`: the data the app reads (indicators, index, water supplies, park boundaries)
- `www/`: static assets, including the methods report
- `tests/`: testthat unit tests and shinytest2 browser smoke tests
- `manifest.json`: deployment manifest for Posit Connect / shinyapps.io

## Running the app

From the repo root in R:

```r
shiny::runApp()
```

## Running the tests

From the repo root:

```bash
Rscript -e 'testthat::test_dir("tests/testthat")'   # unit + smoke tests
Rscript -e 'shinytest2::test_app(".")'              # whole suite via shinytest2
```

Browser smoke tests need Chrome and are skipped when it isn't available.

## Updating app data

The files in `app_data/` are generated by `app_data_prep.Rmd` in [`nps_water_vulnerability`](https://github.com/Water-Vulnerability-Analytics/nps_water_vulnerability).
